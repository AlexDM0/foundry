# Constitution

Obey the rules of this repository. Its `CLAUDE.md`, its `CONTRIBUTING.md` and its code show them. When the code and a
written rule disagree, obey the written rule. When a rule and your task disagree, say so. Do not break the rule
quietly.

Write new tickets, prompts and system md text in ASD-STE100.
Do not use this rule for human-facing documentation. Do not rewrite existing text.
